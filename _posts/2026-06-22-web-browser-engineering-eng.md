Many blog posts about how browsers render web pages are written with a tone that seems to say, “You all know this already, right?” Now that I’ve read this book, I wonder if I’ll understand those kinds of posts a little better. And I’m not sure yet whether it will help me use browser developer tools and debug more effectively.

The book started out easy enough, but as the browser codebase grew, it became increasingly difficult to understand. I suppose commercial browsers are the same way. Still, I can’t help thinking, “This is a bit much.” And this is all before even getting into JavaScript and networking. Even so, of all the books I’ve read so far, this one provides the most detailed treatment of how browsers render what you see on the screen.
